# Avelyn Nguyen — Portfolio Site

This is a static site (plain HTML/CSS/JS, no build step, no Jekyll) meant to be
hosted at `avelynnguyen.github.io` via GitHub Pages.

## Deploying

Upload every file in this folder (`index.html`, `styles.css`, `script.js`,
the `assets/` folder, this README) to the root of your
`avelynnguyen.github.io` repo. If that repo already has files in it from a
template, delete those first — this site doesn't use Jekyll, so leftover
`_config.yml` / `_layouts` / `.md` files from a Jekyll starter can conflict
with it.
